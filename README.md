# Trabalho Facul — Inteligência Artificial

Projeto de portfólio com apresentação acadêmica, desenvolvido por **Bruna Martins**, estudante de Análise e Desenvolvimento de Sistemas.

## Tema
**Inteligência Artificial: fundamentos, aplicações e desafios na sociedade contemporânea.**

## Conteúdo
- Introdução e objetivos do estudo
- Conceitos de IA, Machine Learning e Deep Learning
- Etapas de desenvolvimento de sistemas de aprendizado de máquina
- Aplicações em saúde, educação, negócios e programação
- Riscos, vieses, privacidade e responsabilidade
- Atividade interativa de revisão (quiz com pontuação)
- Considerações finais e referências para aprofundamento

## Tecnologias
HTML5, CSS3 e JavaScript, sem dependências de frameworks.

## Como executar
Abra `index.html` no navegador. Para publicar, use **GitHub Pages** com a branch `main` e pasta `/ (root)`.

## Observação acadêmica
Este é um **projeto acadêmico demonstrativo de portfólio**, não uma entrega comprovada de disciplina específica nem pesquisa empírica. O texto foi escrito como síntese introdutória e inclui fontes para aprofundamento.
